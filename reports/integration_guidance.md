# Integration guidance

Use the carrier's native checkpoint, preprocessing, normalization and action
convention. The supported runner integrations are OpenPI + LIBERO and
OpenVLA-OFT + LIBERO. External benchmark environments use explicit asset
manifests and environment factories.

See the [runtime guide](../docs/runtime.md) for action layouts, frozen feature
providers, probe selection, gate composition and trace records. See
[environment provenance](../docs/environment.md) for version and artifact
capture without importing models.
