# Launchers

This folder provides top-level launch wrappers for the public BAS-VLA scripts.

The wrappers keep release-facing commands easy to discover without changing the underlying script paths.

- `openpi_main_campaign.sh`
- `openpi_formal_triples.sh`
- `openpi_formal_matrix.sh`
- `openpi_appearance_formal.sh`
- `openvla_oft_semantic_break.sh`
